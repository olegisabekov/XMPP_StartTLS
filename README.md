# XMPP_StartTLS
Jabber protocol over startTLS for esp32

Base on https://github.com/huberflores/ArduinoXMPP/tree/master/libraries/XMPP

# Dependencies

Depends on Base64 (https://github.com/Xander-Electronics/Base64). This should be included before Xmpp.h or added to your main library directory.

# Limitations

SASL-PLAIN authentication only
